# stradascholar.com Main Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static Astro site at stradascholar.com with one page per car, parts and tools with buy links and video timestamps, and menu sections, deployed behind Traefik on the Proxmox VM.

**Architecture:** Content lives in `content/` (YAML plus photo folders); the Astro project in `site/` reads it through content collections with a schema and builds static HTML. A multi-stage Docker image builds the site and serves `dist/` with nginx; `deploy.sh` rsyncs the repo to the VM and rebuilds.

**Tech Stack:** Astro 7 (static), TypeScript, plain CSS, `node --test` for helpers, nginx (alpine) container, Traefik v3 labels, yt-dlp + ffmpeg for launch photos.

**Spec:** `docs/superpowers/specs/2026-11-02-main-site-design.md`

## Global Constraints

- Node 24; Astro latest (7.x at time of writing); no UI framework; plain CSS.
- M stripe colours `#81C4FF`, `#16588E`, `#E7222E`; dark by default; light/dark switch remembered in `localStorage` (wrapped in try/catch).
- Menu: Home, Builds, Guides, Tutorials, Coding, Detailing, Fitment, Gear & Tools, Videos. Works at every width from 320px up, including foldables (~280px folded cover screens, ~700-900px unfolded).
- Buy links: US stores; stored plain; affiliate IDs applied at build from `site/src/affiliates.ts`; `target="_blank" rel="sponsored noopener"`.
- No prices. No invented content: only what Lucas says/writes in the four videos.
- Traefik: network `traefik-network`, entrypoint `websecure`, certresolver `ionos`, hosts `stradascholar.com` and `www.stradascholar.com` (www redirects to apex).
- Commit after every task; push to `origin main`.

## Review Focus

- A part with no links renders "No link", never an empty or broken button.
- A part without a video reference renders no watch link (no `t=NaN`).
- A car with no `hero.*` photo falls back to its newest video's YouTube thumbnail.
- An invalid `car.yaml` (missing required field, unknown category) fails the build with the file named.
- Menu at 280px and 360px widths: no horizontal scroll; button opens the full list.

### Task 2: Content schema and helpers

**Files:** Create `site/src/content.config.ts`, `site/src/lib/links.ts`, `site/src/affiliates.ts`, `site/test/links.test.ts`, minimal `content/videos.yaml` and one stub `content/cars/1m/car.yaml`.

**Produces:**
- `buyUrl(store: string, url: string, ids?: Record<string,string>): string` — appends the store's affiliate param when set, else returns `url` unchanged.
- `watchUrl(videoId: string, seconds?: number): string` — `https://www.youtube.com/watch?v=<id>&t=<s>s`, no `t` when seconds is undefined.
- `formatTime(seconds: number): string` — `m:ss` or `h:mm:ss`.
- `thumbUrl(videoId: string): string` — `https://i.ytimg.com/vi/<id>/maxresdefault.jpg`.
- Collections `cars` (glob `../content/cars/*/car.yaml`) and `videos` (file `../content/videos.yaml`).

- [ ] Tests: `formatTime(149) === '2:29'`, `formatTime(3725) === '1:02:05'`; `watchUrl('abc', 149)` ends with `&t=149s`; `watchUrl('abc')` has no `t=`; `buyUrl('amazon', 'https://www.amazon.com/dp/X', {})` unchanged; with `{amazon: 'tag=foo-20'}` gives `...dp/X?tag=foo-20`; URL already holding `?th=1` gets `&tag=foo-20`.
- [ ] Run `node --test site/test/` — fails; implement; passes.
